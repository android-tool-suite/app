# 加载体验优化

本项目是个人工具项目。性能测试服务于具体功能优化，不作为独立发布门槛；不要求温度、电量采集、固定多组跑分、Macrobenchmark 或 Baseline Profile。

## 当前重点

- 返回主页直接显示已有小部件内容，不先切成加载动画。
- 数据修改后自动更新对应摘要；撤销权限后不能继续把旧状态当成有效状态。
- 重复进入插件复用最近页面；被释放后恢复页签与滚动位置。
- 首次进入 Phigros 先显示账号与成绩摘要，再补全完整分析。

## 实现方式

- 宿主 `WidgetSnapshotStore` 在页面之外保留显示字段，数据摘要按包版本、数据代际匹配；系统连接状态不做磁盘恢复。
- Dataset 成功提交、删除和恢复通知对应插件失效；失败或放弃写入不通知。
- 主页保留在详情页下方，当前 Activity 最多保留两个插件页面；停用、替换、销毁时释放旧视图。
- Phigros 和抽卡插件使用自己的 KV 保存轻量页签／滚动位置，不保存登录凭据。
- 抽卡统计按记录 SHA-256 与大小复用计数，写入新记录时生成摘要；恢复旧数据时自动重算。
- Dataset 的完整性校验继续执行。本次减少重复查询和重复传输，没有跳过完整性校验。

## 少量实际操作即可验证

1. 冷启动查看摘要；主页与同一插件往返一次，确认内容、页签保留且未重复创建 WebView。
2. 打开第三个插件后回到最早插件，确认轻量状态恢复。
3. 修改或恢复一份数据，确认对应摘要更新；撤销并恢复权限，确认组件状态同步。

当前先使用图形模拟器与实际导出数据，不模拟 Capability 成功，不代替授权确认流程。需要定位时只保存相关日志和截图，不启动多组性能采样。模拟器结果用于验证行为，不据此承诺实体设备加载毫秒数。

后续只有遇到可复现的新卡顿，再为那个具体路径补充测量；不预先建设整套性能验收体系。
